# 体态健康日记 (PostureHealth Diary) - 技术规范

## 1. 项目概述

**项目名称**: 体态健康日记
**项目类型**: 全栈Web应用 (Python Flask + SQLite + HTML5/CSS3/JS)
**核心功能**: 帮助用户追踪日常体态健康状况，记录疼痛、睡眠、运动数据，提供康复动作建议和数据分析
**目标用户**: 需要关注颈肩腰背健康的上班族、久坐人群

---

## 2. 技术架构

### 后端
- **框架**: Python Flask 2.x
- **数据库**: SQLite (通过SQLAlchemy ORM)
- **API风格**: RESTful JSON API
- **模板引擎**: Jinja2

### 前端
- **结构**: HTML5 单页面应用 (SPA)
- **样式**: 纯CSS3 (响应式设计)
- **图表**: Chart.js 4.x
- **日历**: 自定义日历组件
- **图标**: Lucide Icons (CDN)

### 数据存储
- **SQLite数据库**: `/data/health_diary.db`
- **表结构**:
  - `daily_records`: 每日记录 (日期、疼痛评分、睡眠、运动、心情)
  - `symptoms`: 症状记录 (部位、类型、原因、日期)
  - `exercise_logs`: 康复动作完成记录
  - `exercises`: 康复动作库

## 4. 功能模块详细规范

### 4.1 每日记录 (Daily Record)

**数据字段**:
| 字段 | 类型 | 说明 |
|------|------|------|
| date | DATE | 记录日期 |
| neck_pain | INT(0-10) | 颈部疼痛程度 |
| shoulder_pain | INT(0-10) | 肩部疼痛程度 |
| waist_pain | INT(0-10) | 腰部疼痛程度 |
| back_pain | INT(0-10) | 背部疼痛程度 |
| sleep_hours | FLOAT | 睡眠时长(小时) |
| sleep_quality | INT(1-5) | 睡眠质量(1-5星) |
| exercise_minutes | INT | 运动时长(分钟) |
| mood_score | INT(1-10) | 心情指数 |

**交互设计**:
- 疼痛程度使用滑块 (0-10)
- 睡眠时长使用数字输入框
- 睡眠质量使用星级评分
- 心情指数使用表情符号选择器 (😊😀😐😕😢)

### 4.2 症状追踪 (Symptom Tracking)

**数据字段**:
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| date | DATE | 记录日期 |
| body_part | ENUM | 部位(neck/shoulder/waist/back) |
| symptom_type | ENUM | 症状(酸痛/麻木/僵硬/刺痛/无力) |
| possible_cause | TEXT | 可能原因(可选) |
| notes | TEXT | 备注说明(可选) |

**交互设计**:
- 部位选择: 身体部位图示点击
- 症状类型: 下拉选择
- 原因: 预设选项 + 自定义输入
  - 预设: 久坐、剧烈运动、受凉、压力大、睡姿不当

### 4.3 康复动作库 (Exercise Library)

**内置10个动作**:
1. 颈部米字操 - 缓解颈部僵硬
2. 肩部旋转 - 放松肩关节
3. 猫牛式伸展 - 脊柱灵活性
4. 胸椎旋转 - 改善背部不适
5. 平板支撑 - 核心肌群强化
6. 臀桥 - 腰部放松
7. 鸟狗式 - 平衡与稳定
8. 门框伸展 - 胸部打开
9. 死虫式 - 核心训练
10. 婴儿式放松 - 全身放松

**每日推荐逻辑**:
- 根据当日记录的疼痛部位智能推荐
- 每次推荐3-5个动作
- 用户可勾选完成状态
- 记录完成时间

**动作数据结构**:
```python
{
    "id": INT,
    "name": STR,
    "description": STR,
    "duration_seconds": INT,
    "target_parts": [LIST],  # ["neck", "shoulder", "waist", "back"]
    "difficulty": ENUM,  # easy/medium/hard
    "icon": STR  # emoji
}
```

### 4.4 数据分析 (Data Analytics)

**本周疼痛趋势折线图**:
- X轴: 日期 (周一至周日)
- Y轴: 疼痛程度 (0-10)
- 4条线: 颈部/肩部/腰部/背部
- 颜色: 颈部(#FF6B6B), 肩部(#FFE66D), 腰部(#45B7D1), 背部(#96E6A1)

**睡眠与疼痛相关性**:
- 散点图展示睡眠时长与各部位疼痛关系
- 计算相关系数

**每周健康报告**:
- 生成时间: 每周日晚8点自动生成
- 内容结构:
  ```
  📊 本周健康周报

  📈 整体趋势:
  - 本周平均疼痛程度: X/10
  - 较上周变化: ↑↓X%

  🏆 最佳表现日:
  - 日期: X月X日
  - 状态描述

  ⚠️ 需关注:
  - 部位: X
  - 建议动作: X

  💡 康复建议:
  - 具体建议列表
  ```

### 4.5 提醒功能 (Reminders)

**久坐提醒**:
- 每45分钟触发一次
- 浏览器Notification API
- 内容: "该站起来活动一下了！试试做几个伸展动作。"
- 用户可开启/关闭

**晚间记录提醒**:
- 每天晚上8点提醒
- 浏览器Notification API
- 内容: "今日体态记录还没填写哦，点击开始记录！"
- 用户可开启/关闭

**实现方式**:
- 前端定时器检测
- 存储在 localStorage 的设置状态
- 需要用户授权通知权限

### 4.6 健康日历 (Health Calendar)

**月度视图**:
- 显示当前月份的日历
- 每个日期格子显示疼痛指示
- 颜色规则:
  - 全部无痛 (≤2): 绿色背景 #4ECDC4
  - 轻度疼痛 (3-5): 橙色背景 #FFA94D
  - 中度疼痛 (6-7): 浅红背景 #FFB3B3
  - 重度疼痛 (8-10): 红色背景 #FF6B6B
  - 无记录: 灰色背景 #E0E0E0

**交互**:
- 点击日期查看详情
- 左右箭头切换月份
- 显示当月统计摘要

### 4.7 历史记录管理

**功能**:
- 查看所有历史记录
- 按日期筛选
- 编辑/删除记录
- 导出数据为CSV

## 6. API 端点设计

### 记录相关
- `GET /api/records` - 获取所有记录
- `GET /api/records/<date>` - 获取指定日期记录
- `POST /api/records` - 创建/更新记录
- `DELETE /api/records/<date>` - 删除记录

### 症状相关
- `GET /api/symptoms` - 获取所有症状
- `GET /api/symptoms?date=<date>` - 获取指定日期症状
- `POST /api/symptoms` - 添加症状记录
- `DELETE /api/symptoms/<id>` - 删除症状

### 动作相关
- `GET /api/exercises` - 获取所有动作
- `GET /api/exercises/recommended` - 获取每日推荐
- `POST /api/exercises/complete` - 记录完成动作

### 数据分析
- `GET /api/analytics/weekly` - 获取本周数据
- `GET /api/analytics/calendar/<year>/<month>` - 获取月历数据
